Graph2Font

- dla plików GED wymusza ustawienie MODE=GED+
- zapamietuje oddzielnie nazwy plikow dla SWAP WORKING AREA i głównego ekranu
- dla trybu g10 zapisuje MIC i odczytuje MIC z 9 wartościami rejestrów koloru (standardowo MIC zapisuje tylko 4 wartości)
- poprawiony odczyt/zapis limitu (*.LMT) dla kompresji znakow
- dodana obsługa brush-y pod Zoom-em
- po zapisie przez 'Save As...' wraca domyślnie do zapisywania pliku G2F 'Save'
- pod ZOOM-em, zmiana powiększenia klawiszami '+', '-' nie powoduje wstawienia inwersu znaków
